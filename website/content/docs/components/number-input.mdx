---
title: NumberInput
description: Edits a number within bounds, with a stepper and optional drag scrubbing.
---

<Example name="number-input" height={240} />

Valid text updates the value as it is typed; partial or invalid text is kept while editing and restored on Enter or when focus leaves. The arrow keys and stepper buttons add or subtract `step`, clamped to the bounds.

`LeadingText` or `LeadingIcon` adds a handle that changes the value as it is dragged sideways, as design tools do. `HideStepper` removes the buttons.

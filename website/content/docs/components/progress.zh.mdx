`components.Progress` 和 `components.ProgressRing` 显示 0 到 1 之间的进度，并在变化时以动画过渡。

## 加载指示器

`components.Spinner` 表示时长未知的工作，可以是与 `ProgressRing` 相同的圆环，也可以是渐隐的辐条。用 `Label` 为它命名。开启减少动态效果时它会停止转动。

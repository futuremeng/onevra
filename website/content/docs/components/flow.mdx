---
title: Flow diagram
description: Directed diagrams laid out in ranks, with orthogonal edges and card nodes.
---

<Example name="flow" height={440} />

`flow.View` ranks nodes so edges stay short, orders each rank to reduce crossings and routes edges between ranks. Nodes build their own content, or use `flow.Card`, whose regions are slots. Click a node to select it; the application owns selection and opening.

`components.Tabs` 把选中的索引绑定到一个 `*int`。`TabsUnderline` 适合页面分区，`TabsSegmented` 可替代分段控件，`TabsHighlight` 在选中的标签后方滑动一块柔和的底色。

## 插槽与菜单

`TabsWith` 接收选项：`Leading` 和 `Trailing` 在每个标签旁构建内容，例如图标或计数；`Menu` 为标签提供右键菜单。

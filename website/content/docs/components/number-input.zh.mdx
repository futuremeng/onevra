---
title: NumberInput
description: 在范围内编辑数字，带步进按钮，并可拖动调整。
---

<Example name="number-input" height={240} />

有效的文字会在输入时立即更新数值；不完整或无效的文字在编辑时保留，并在按下 Enter 或失去焦点时恢复。方向键和步进按钮按 `step` 增减，并限制在范围内。

`LeadingText` 或 `LeadingIcon` 会添加一个横向拖动即可改变数值的手柄，就像设计工具那样。`HideStepper` 移除步进按钮。

<Example name="tabs" height={220} />

`components.Tabs` binds the selected index to an `*int`. `TabsUnderline` suits page sections, `TabsSegmented` replaces a segmented control, and `TabsHighlight` slides a soft block behind the chosen label.

## Slots and menus

`TabsWith` takes options: `Leading` and `Trailing` build content beside each label, such as an icon or a count, and `Menu` gives a tab a context menu.

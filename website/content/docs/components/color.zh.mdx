`components.ColorPicker` 是一个色块，点击后在弹出层中打开编辑器。可以用 `Size`、`Radius`、`Border` 和 `Padding` 改变它的形状。

## 编辑器

`components.ColorView` 直接编辑颜色：包含饱和度与亮度平面、色相和不透明度滑块，以及 RGB、HSB 或 HSL 字段和十六进制字段。它的菜单可以把颜色复制为文本。

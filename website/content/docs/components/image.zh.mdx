`components.Image` 显示应用已解码的 `*ui.Bitmap` 或 `*ui.SVG`。默认按 contain 方式适配；`Fit(ui.Cover)` 会裁剪以填满。不要在构建函数中加载或解码图片。

## 对比

`components.ImageCompare` 把一个视图叠在另一个之上，并通过可拖动的分隔线显示前者。在任意位置按下即可把分隔线移到那里；对键盘而言，手柄是一个滑块。

`components.Progress` and `components.ProgressRing` show a fraction from 0 to 1, animating as it changes.

## Spinners

`components.Spinner` shows work of unknown length, as a ring like `ProgressRing`'s or as fading spokes. Name it with `Label`. Reduced Motion freezes it.

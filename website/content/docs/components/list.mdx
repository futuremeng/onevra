title: List
description: A virtualized list of rows with keyboard selection.
---

<Example name="list" height={360} />

`components.List` builds only the visible rows, so it handles long lists. The application builds each row's content; `ListState` holds selection, keys and callbacks such as `OnSubmit` for Enter and double clicks.

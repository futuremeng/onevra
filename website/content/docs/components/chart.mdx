The `chart` package draws categorical charts. The application keeps the data and a `chart.State` per chart, gives series and slices stable IDs, and supplies labels and formatting. Hover, or focus the chart and use the arrow keys, to select a category; its details show in a tooltip. Start with `chart.State{Index: -1}` for no selection.

Data changes animate: values move to their new places, and Reduced Motion skips the transition. These charts suit bounded datasets; aggregate or sample large data before passing it in.

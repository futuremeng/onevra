---
title: Breadcrumbs
description: Shows a path whose ancestors can be chosen, collapsing the middle when space runs out.
---

<Example name="breadcrumbs" height={160} />

Activating an ancestor writes its index and reports `Changed()`; the application navigates. The path fills its parent's width, and when it does not fit, the middle ancestors collapse into a menu. Narrow the window to see it.

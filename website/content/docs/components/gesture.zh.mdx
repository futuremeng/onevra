title: 手势
description: 为自定义画布提供平移和缩放，支持滚轮、触控板和双指捏合。
---

<Example name="gesture" height={360} />

`gesture.Navigation` 把元素的滚动输入转换为平移和缩放事件：触控板平移，双指捏合缩放，鼠标滚轮缩放。每个元素保留一个 Navigation，并把事件应用到你自己的视角上。关系图和流程图就是用它实现的。

浏览器不会报告触控板的捏合手势，因此在本文档中，捏合会以 Control 加滚动的形式到达，与 Windows 上的情况相同。

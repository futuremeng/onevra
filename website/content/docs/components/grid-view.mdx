---
title: GridView
description: A virtualized, responsive grid of cells, such as photos or files.
---

<Example name="grid-view" height={360} />

Give each cell a minimum width and a height; the grid fits as many per row as the width allows and builds only the visible cells. Selection and activation follow `GridState`.
